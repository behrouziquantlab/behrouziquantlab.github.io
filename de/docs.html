Dokumentation

Installation

Datei → Datenordner öffnen → .ex5 nach MQL5\Indicators\BQL kopieren → Navigator → Aktualisieren → auf einen M1- oder M5-Chart ziehen.

Einstellungen

Engines (M5/M1, schnell/Standard, Swing-Größe), Anzeige (regulär/versteckt, bildend, Linien, Labels, Panel) und Alarme (Popup/Ton/Push je Stufe und Zeitrahmen).

Labels lesen

HD▲ M5·S = bestätigte versteckte bullische Divergenz, M5, Standard-MACD. „?“ markiert ein sich bildendes Signal.

Bekannte Grenzen

In v1.0 nur M1/M5; Konvergenzen werden berechnet, aber nicht angezeigt.

Der Handel ist mit erheblichen Risiken verbunden. BQL-Tools analysieren Märkte und senden Alarme; sie platzieren niemals Trades. In unseren veröffentlichten Tests zeigte Divergenz allein keinen statistischen Vorteil – nutzen Sie sie als einen Baustein Ihres eigenen Prozesses.
