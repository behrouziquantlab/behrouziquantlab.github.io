Install in five minutes

  1. In MetaTrader 5 open File → Open Data Folder.
  2. Copy BQL_PreCross.ex5 to MQL5\Indicators\.
  3. Go one folder up, open Common → Files and copy the four BQLP_HLCI_DB_*.bin files there.
  4. Put your licence file BQLP_licence.txt in the same Common → Files folder (or paste the key into the input "Licence key").
  5. Restart MT5 and drag BQL_PreCross onto a chart of EURAUD, AUDUSD, NZDUSD or USDCHF (M1 recommended).
  6. For phone alerts: Tools → Options → Notifications, enter your MetaQuotes ID.

Reading the panel

  1. HLCI · state — where the current move stands according to the 5-year memory.
  2. HLCI · up / down % — share of the 100 most similar past situations followed by an up or down cross.
  3. ▲ / ▼ cross expected — an open warning with direction, probability and bars passed.
  4. Window — the server-time window of the expected cross (3 to 7 M5 bars after the warning).
  5. Results so far — how the warnings on this chart actually resolved.

Good to know

  1. The indicator never opens, closes or modifies orders.
  2. Demo accounts also need a licence (no free trial).
  3. Alerts and part of the panel text are in Persian in release 2.0.
