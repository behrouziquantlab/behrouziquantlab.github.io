安装

文件 → 打开数据文件夹 → 将 .ex5 复制到 MQL5\Indicators\BQL → 导航器 → 刷新 → 拖到 M1 或 M5 图表。

设置

引擎（M5/M1、快速/标准、摆动大小）、显示（常规/隐藏、形成中、连线、标签、面板）与提醒（按阶段和周期的弹窗/声音/推送）。

读懂标签

HD▲ M5·S = 已确认的隐藏看涨背离，M5，标准 MACD。“?”表示形成中的信号。

已知局限

v1.0 仅支持 M1/M5；收敛事件会计算但不显示。
