نصب در پنج دقیقه

  1. در متاتریدر ۵ مسیر File ← Open Data Folder را باز کنید.
  2. فایل BQL_PreCross.ex5 را در MQL5\Indicators\ کپی کنید.
  3. یک پوشه بالا بروید، Common ← Files را باز کنید و چهار فایل BQLP_HLCI_DB_*.bin را آنجا کپی کنید.
  4. فایل لایسنس BQLP_licence.txt را در همان پوشه‌ی Common ← Files بگذارید (یا کلید را در ورودی «Licence key» بچسبانید).
  5. MT5 را دوباره باز کنید و BQL_PreCross را روی چارت EURAUD، AUDUSD، NZDUSD یا USDCHF بکشید (M1 پیشنهاد می‌شود).
  6. برای هشدار روی گوشی: Tools ← Options ← Notifications و وارد کردن MetaQuotes ID.

خواندن پنل

  1. HLCI · وضعیت — حرکت فعلی طبق حافظه‌ی ۵ ساله کجاست.
  2. HLCI · درصد صعود / نزول — سهم ۱۰۰ موقعیت مشابه گذشته که با کراس صعودی یا نزولی همراه شدند.
  3. ▲ / ▼ کراس مورد انتظار — هشدار باز با جهت، احتمال و تعداد کندل گذشته.
  4. بازه — بازه‌ی زمانی کراس مورد انتظار به ساعت سرور (۳ تا ۷ کندل M5 پس از هشدار).
  5. نتیجه تاکنون — هشدارهای همین چارت واقعاً چه شدند.

خوب است بدانید

  1. اندیکاتور هرگز سفارش باز، بسته یا ویرایش نمی‌کند.
  2. حساب دمو هم لایسنس می‌خواهد (نسخه‌ی آزمایشی رایگان ندارد).
  3. در نسخه‌ی 2.0 هشدارها و بخشی از متن پنل فارسی است.
