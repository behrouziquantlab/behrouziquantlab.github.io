Documentation

Installation

File → Open Data Folder → copy the .ex5 to MQL5\Indicators\BQL → Navigator → Refresh → drag onto an M1 or M5 chart.

Settings

Engines (M5/M1, fast/standard, swing size), display (regular/hidden, forming, lines, labels, panel) and alerts (popup/sound/push per stage and timeframe).

Reading labels

HD▲ M5·S = confirmed hidden bullish divergence, M5, standard MACD. A "?" marks a forming signal.

Known limitations

M1/M5 only in v1.0; convergence events are computed but not displayed.

Trading involves substantial risk. BQL tools analyse markets and send alerts; they never place trades. In our own published tests divergence alone showed no statistical edge — use it as one input of your own process.
